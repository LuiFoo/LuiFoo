<h2>🚀 Featured Projects</h2>

### 📦 Inventory Management System — FMRP-USP

Full Stack web application developed for the IT Department at FMRP-USP, currently running in production and used in daily inventory operations.

The system replaced spreadsheet-based workflows with a centralized platform for managing IT equipment and materials.

- Inventory management and stock tracking
- Incoming and outgoing item records
- Complete movement history and traceability
- Low-stock monitoring and inventory checks
- Dashboard and report generation

**Tech Stack:** React · Node.js · MongoDB · Docker

### 📅 Beauty Studio Booking & Management System

Web application developed for a beauty studio, currently running in production and used for daily appointment scheduling and business management.

The platform allows customers to book appointments online while providing the business owner with tools to manage services and operations.

- Online appointment scheduling
- Client management and appointment history
- Service and availability management
- Payment tracking
- Website customization and ongoing improvements

### 🛒 Bakery E-commerce & Delivery Management

Full Stack web application designed to simplify online sales, order processing, and delivery management for a bakery.

- Product catalog and shopping cart
- User authentication
- Administrative dashboard
- Product and order management
- Order status tracking

**Tech Stack:** React · Node.js · MongoDB
